# S’Up Mobile App

S’Up is a React Native (Expo) mobile app for supporting posture health.

---

## Tech Stack

- React Native
- Expo (managed workflow)
- Expo Router
- TypeScript
- Supabase (planned)

---

## Setup

### 1. Install dependencies
```bash
npm install
```

### 2. Start the app
```bash
npx expo start
```

## 3. Running the App

- Scan the QR code with **Expo Go**
- Press `i` for iOS simulator
- Press `a` for Android emulator
